# LAN Chat
Windows 局域网聊天程序，提供房主可自行启动的 TLS 服务端和中文桌面客户端，支持频道、私信、历史消息与文件附件。

## 快速开始

从[发布页](https://github.com/DUSK1NG/cross-language-lan-chatroom/releases/latest)下载 `LANChat-Setup-x64.exe` 安装，或完整解压 `LANChat-Windows-x64.zip` 后运行 `LANChat.exe`。

房主选择“创建本地聊天室”，填写用户名与用户代码并启动。成员选择“加入局域网聊天室”，在“附近聊天室”中选择房主，核对公开证书指纹后申请加入；房主批准后进入聊天室。

## 使用

可使用公开或私有频道、频道邀请、一对一私信、离线消息、历史记录、撤回与管理员操作。附件支持上传、续传和下载解密；跨机器与大文件传输需按[验收清单](docs/release-acceptance.md)实测。

自动发现、手动连接、虚拟局域网及 TCP 隧道的操作见[局域网使用说明](docs/release-setup.md)。程序适用于彼此信任的网络，每次成员连接须由房主确认。

## 配置

首次创建聊天室会在当前用户的本地应用数据目录生成服务端证书、私钥和数据库。只向成员共享公开证书；私钥、数据库和聊天记录不得打包或公开。首次加入应通过可信渠道核对证书指纹。
