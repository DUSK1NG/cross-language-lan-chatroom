# 管理员权限

## 配置远程服务端管理员

启动 Go 服务端时指定管理员用户代码：

```powershell
.\chat-server.exe `
  -cert .\certs\server.crt `
  -key .\certs\server.key `
  -admin-code ALICE001
```

代码比较不区分大小写。管理员必须使用该代码对应的账号登录。

## GUI 管理操作

管理员在成员资料面板中可以踢出成员或切换禁言状态，客户端会先显示中文确认提示；服务端再根据当前连接的管理员身份执行操作，普通成员不能伪造管理请求。

频道创建者与全局管理员可以点击频道顶部的齿轮：

- 输入成员代码后邀请成员进入私有频道；
- 移除频道成员，在线成员会被送回 `lobby`；
- 删除频道，所有在线成员都会返回 `lobby`。

频道创建者的权限仅针对自己创建的频道；全局管理员可管理任意频道。频道权限与邀请名单目前只在服务端运行期间有效。

## Host 模式

Qt GUI 的“创建本地聊天室”模式会把房主的用户代码作为 `-admin-code` 传给本机 Go 服务端，因此房主会自动获得管理员权限。

管理员权限只保存在当前服务端进程内，不会把权限写入账号数据库。
