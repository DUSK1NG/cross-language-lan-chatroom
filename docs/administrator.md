# 管理员权限

## 配置远程服务端管理员

启动局域网服务端时指定管理员用户代码。

```powershell
.\lan-chat-server.exe `
  -cert .\certs\server.crt `
  -key .\certs\server.key `
  -admin-code ALICE001
```

代码比较不区分大小写。管理员必须使用该代码对应的账号登录。

## GUI 管理操作

管理员在成员资料面板中可以踢出成员或切换禁言状态，客户端会先显示中文确认提示；服务端再根据当前连接的管理员身份执行操作，普通成员不能伪造管理请求。

频道创建者与全局管理员可以点击频道顶部的齿轮：

- 输入成员代码后邀请成员进入私有频道；
- 移除频道成员，在线成员会被送回 `lobby`；
- 删除频道，所有在线成员都会返回 `lobby`。

频道创建者和房主可任免频道管理员、修改私密频道密码或删除频道。频道管理员可管理本频道的成员及撤回本频道消息。旧客户端可以照常加入和聊天，频道管理员操作需要双方支持 `lan-room-roles-v1`。

普通频道、私密频道、邀请名单、密码与频道管理员在房主重启后保留。房主设置的频道发言禁言按用户代码保存，在所有频道继续生效。修改密码后，新加入的连接使用新密码。

## Host 模式

“创建本地聊天室”首次启动时设置房主密码，以后启动时验证该密码。验证通过后，本机房主以填写的用户代码取得管理员权限。访客使用自己的用户代码并等待房主批准。

访客每次建立连接都需房主审批，频道白名单只影响审批后的频道访问。
