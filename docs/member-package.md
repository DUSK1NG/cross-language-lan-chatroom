# LAN Chat 成员包使用说明

此说明适用于统一运行包中作为成员加入已创建聊天室的场景。它不包含初始私钥、数据库、聊天记录、源码或自动编译工具。

## 加入聊天室

1. 解压整个压缩包，不要只复制 `LANChat.exe`。
2. 双击根目录的 `LANChat.exe`。
3. 选择“加入局域网聊天室”。
4. 在“附近聊天室”中选择房主，填入自己的用户名和用户代码，点击“确认并加入”。
5. 首次加入时，程序会自动保存房主的公开证书并固定校验其指纹；无需手动复制 IPv4 或证书。

若自动发现被网络阻止，使用“改用手动连接”，填入房主真实 IPv4、端口 `8888` 和公开证书 `server-lan.crt`；跨电脑不能使用 `127.0.0.1` 或 `0.0.0.0`。

## 连接失败

在成员电脑的 PowerShell 中执行：

```powershell
Test-NetConnection <房主IPv4> -Port 8888
```

如果测试失败，请让房主确认服务端正在监听、Windows 防火墙允许 TCP 8888 的专用网络访问，并确认双方不在访客网络、AP/Client Isolation 或隔离 VLAN。成员机接收 UDP 38888 广播失败时可回退到手动连接。

## 安全

只接收 `.crt` 公开证书。绝不要索取、保存或发送 `server-lan.key`、任何 `.key`/`.pem` 文件、`chat.db` 或聊天记录。
