# LAN Chat 成员包使用说明

此压缩包只用于加入已经由房主创建的局域网聊天室。它不包含服务端、私钥、数据库、聊天记录、源码或自动编译工具。

## 加入聊天室

1. 解压整个压缩包，不要只复制 `lan-chat-gui.exe`。
2. 双击根目录的 `lan-chat-gui.exe`。
3. 选择“加入局域网聊天室”。
4. 向房主索取：房主的局域网 IPv4、端口（默认 `8888`）以及公开证书 `server-lan.crt`。
5. 填入自己的用户名和用户代码，选择房主提供的 `.crt` 后连接。

同一台电脑测试可以使用 `127.0.0.1`；从另一台电脑加入时，必须使用房主真实的局域网 IPv4，不能使用 `127.0.0.1` 或 `0.0.0.0`。

## 连接失败

在成员电脑的 PowerShell 中执行：

```powershell
Test-NetConnection <房主IPv4> -Port 8888
```

如果测试失败，请让房主确认服务端正在监听、Windows 防火墙允许 TCP 8888 的专用网络访问，并确认双方不在访客网络或隔离 VLAN。

## 安全

只接收 `.crt` 公开证书。绝不要索取、保存或发送 `server-lan.key`、任何 `.key`/`.pem` 文件、`chat.db` 或聊天记录。
