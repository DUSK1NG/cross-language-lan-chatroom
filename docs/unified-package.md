# LAN Chat Windows 统一包

此包可在任何 Windows 电脑上使用：房主选择“创建本地聊天室”，成员选择“加入局域网聊天室”。不需要安装 Node.js、Go、CMake 或 Qt。

## 作为房主

1. 双击 `LANChat.exe`。第一次打开时，启动器会先生成本机专用的 TLS 证书、私钥和数据库；随后选择“创建本地聊天室”。
2. 填写用户名和用户代码，点击“启动并连接”。
3. 程序启动本机 Go Server 并连接；首次启动时生成的本机专用 `server-lan.crt`、`server-lan.key` 位于 `server-go\certs\`，本地数据位于 `server-go\chat.db`。
4. 房间会自动出现在成员的“附近聊天室”列表中；保持房主程序运行即可。

## 作为成员

1. 双击同一个 `LANChat.exe`，选择“加入局域网聊天室”。
2. 在“附近聊天室”选择房主，填写自己的用户名和用户代码，点击“确认并加入”。
3. 第一次确认会保存并固定校验房主的公开证书，IPv4 变化后程序仍会自动发现。

自动发现不可用时，点“改用手动连接”，再填写房主真实 IPv4、端口 `8888` 和 `server-lan.crt`。跨电脑手动连接不能使用 `127.0.0.1`。如需排查网络，请运行：

```powershell
Test-NetConnection <房主IPv4> -Port 8888
```

## 安全

- 包内不含证书、私钥、数据库或聊天记录。
- `server-lan.key` 只留在房主电脑，绝不能发送给成员或上传 GitHub。
- 自动发现只传递公开证书和指纹，绝不传递私钥；在不可信网络首次加入前应核对指纹。手动连接时房主可分享 IPv4、端口和 `server-lan.crt`。
