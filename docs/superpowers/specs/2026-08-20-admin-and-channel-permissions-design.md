# 管理员菜单与频道权限设计

## 目标

在不改变现有 TLS/TCP 长度帧协议基础的前提下，将已经存在的全局管理员能力可靠地呈现在 Qt GUI 中，并为频道加入最小可用的权限模型。

本轮分两个递进步骤交付：先验证与补齐全局管理员菜单，再增加频道创建者和私密频道权限。普通用户绝不能通过客户端伪造身份获得管理能力。

## 现状与问题

当前 Go Hub 已经根据 `-admin-code`（房主模式自动传入房主用户代码）设置 `Client.IsAdmin`，并在 Hub 单 goroutine 中处理 `kick`、`mute` 与 `recall`。Qt 客户端也已在成员资料弹窗中调用 `admin_action`。

现有频道只有名称和在线成员集合：任何用户都能创建或加入任意名称；频道不会持久化；用户列表响应也没有成员管理员标识。因此频道权限不能仅靠 QML 隐藏按钮，必须由 Go Hub 负责最终授权。

## 方案

### 第一步：全局管理员菜单验收与补齐

保持现有 `admin_action` 消息类型和 `kick`、`mute`、`recall` 行为不变。

- 成员资料弹窗：对非本人、非管理员成员显示“禁言/解除禁言”和“踢出”。
- 管理操作前展示中文确认对话框；执行后依赖服务端 `system` 或 `error` 消息反馈结果。
- 全局管理员自己与其他管理员不显示管理操作，防止误操作。
- 为 Hub 行为补充测试：无管理员权限、操作自己、目标不存在、禁言切换、踢出、撤回。
- GUI 仅使用登录响应中的 `is_admin` 决定是否显示控制项；服务端仍再次检查 `Client.IsAdmin`。

### 第二步：频道权限

将 `RoomNames map[string]struct{}` 演进为 Hub 独占的 `RoomDefinitions map[string]*Room`；现有 `Rooms map[string]map[*Client]bool` 保留并重命名为 `RoomMembers`，只负责在线成员集合。`Room` 至少包含：名称、创建者规范化用户代码、访问级别（公开或私密）和被允许加入私密频道的用户代码集合。lobby 始终公开，且没有创建者。

- 新增 `room_create`：创建者成为频道所有者；创建时选择“公开”或“私密”。
- `room_join`：公开频道允许所有在线用户加入；私密频道仅允许频道所有者、全局管理员或已获邀请的成员进入。
- 新增频道管理操作：频道所有者或全局管理员可邀请成员、移除成员、切换公开/私密。
- 频道所有者离线不会删除频道；本版本频道权限只保存在服务端内存，服务端重启后回到 lobby 和默认频道状态。
- 全局管理员可以管理所有频道；频道所有者只能管理自己的频道，不能使用全局禁言、踢出或撤回权限。

## 客户端界面

“新建频道”对话框增加访问级别选择。频道标题的设置按钮仅对频道所有者和全局管理员可用，打开“频道设置”弹窗：显示频道类型、邀请在线成员、移除已加入成员和切换访问级别。

成员资料弹窗继续承担“主页、私聊、全局管理员动作”；频道成员管理放在频道设置中，避免把频道权限和全局封禁混为一谈。

## 数据流与安全边界

```text
QML 点击管理操作
  -> ChatController / Worker
  -> 4-byte length + JSON admin_action 或 room_action
  -> Go Client 校验帧
  -> Hub 单 goroutine 校验操作者和频道权限
  -> 仅向相关用户发送 system/error/rooms_response
```

客户端传入的用户代码、频道名和操作类型都只能视为请求参数。Hub 从当前 TCP 连接取得真实操作者身份，且不允许客户端直接修改 Room、Muted 或 IsAdmin 状态。

## 错误处理

- 非法频道名、未知用户、未知频道和不允许加入均返回明确 `error`。
- 频道所有者不能把自己从自己的频道移除；全局管理员可覆盖该限制。
- 被禁言用户仍可浏览频道和接收消息，但服务端拒绝其群聊发送。
- 频道操作不会阻塞 Hub；对已断开的目标用户按“目标不在线”处理。

## 验收

1. 房主登录后，点击普通成员能看到禁言和踢出；普通成员看不到。
2. 禁言后目标无法发送群聊，解除后恢复；踢出后目标断开。
3. Alice 创建私密频道，Bob 未邀请时无法加入；邀请后可加入并聊天。
4. Bob 不能修改频道访问级别、邀请或移除其他成员。
5. 全局管理员可管理任意频道；第三个用户收不到私聊和频道无关的管理提示。
6. Go 测试、Qt CMake 构建和双客户端 localhost 测试通过。
