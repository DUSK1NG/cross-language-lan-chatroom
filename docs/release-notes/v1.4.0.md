# LAN Chat 1.4.0

局域网版与在线版合并到同一条代码线后的首个正式版。桌面端补齐动效与聊天交互，Windows 在线版接入 AstrBot 机器人设置，Windows 在线版与 Android 新增群角色、群公告、群图片与群文件。

## 新增

- 桌面端「设置 → 动效」可分别控制新文字淡入、消息气泡动画和聊天区滚动动画；关闭后立即停止播放，系统开启「减少动态效果」时自动精简。
- 聊天交互细化：消息悬停与选择收进气泡内，表情面板按分类切换，搜索展开时让出标题空间，输入框按宽度重排草稿行。
- Windows 在线版「设置 → 机器人」接入 AstrBot：读取、新建和编辑模型源、模型与人格，模型 API Key、提示词和自定义出错回复保存在 AstrBot。OpenAPI Key 可按账号加密同步。
- Windows 在线版与 Android 支持群角色、群公告、群图片与群文件，Android 版本号为 0.4.0。

## 改进

- 局域网客户端与服务端协商心跳，断线后可重新连接，重连仍由房主审批。
- 普通频道、私密频道、密码、白名单、频道管理员及禁言可在房主重启后恢复。
- 会话搜索支持中文短词、符号与分页，撤回的消息会从搜索结果中移除。
- 设置的「关于」提供手动检查更新：安装版验证签名后下载安装，便携版提供新版 ZIP 下载入口。
- LAN 文件校验和读写在独立附件任务执行，聊天可在大文件提交期间继续收发。
- Online 历史可搜索，在线文件与图片使用磁盘存储，并保留读取旧历史附件的能力。

## 修复

- 修复附件已上传但附件消息被限流拦截的问题。
- 修复输入法组字未上屏时点发送会把原始拼音当成消息发出的问题；Android 组字期间不再写入草稿。
