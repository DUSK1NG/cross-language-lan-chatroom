# LAN Chat 1.4.0

- 局域网客户端和服务端协商心跳，断线后重新连接仍由房主审批。
- 会话搜索支持中文短词、符号和分页，撤回的消息会从搜索结果中移除。
- 普通频道、私密频道、密码、白名单、频道管理员及禁言可在房主重启后恢复。
- 设置的「关于」提供手动检查更新。安装版验证签名后可下载安装，便携版提供新版 ZIP 下载入口。
- 修复文件已上传但附件消息被限流拦截的问题。
- LAN 文件校验和读写在独立附件任务执行，聊天可在大文件提交期间继续收发。
- Online 历史可搜索，在线文件与图片使用磁盘存储，保留读取旧历史附件的能力。
- Windows Online 和 Android 支持群角色、群公告、群图片与文件。Android 版本为 0.4.0。
