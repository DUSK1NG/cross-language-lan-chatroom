# LAN Chat 1.4.1

一次专门收拾「打断人」的小版本：草稿、选中的房主、审批弹窗、保存失败和 Android 传文件都不再把你从正在做的事里拽出来。桌面局域网版、在线版与 Android 0.4.1 同步更新。

## 新增

- 新的连接申请才弹审批窗；弹窗可以随时收起继续聊天，待批准提示保留在标题角标与成员面板中。
- 在线版首次启动预置公共服务器，地址与端口收进「更改服务器」，需要换服务器时才展开。

## 改进

- 切到设置页再回到聊天，输入框里的草稿仍然保留。
- 局域网扫描保留仍在广播的主机；选中的房主短暂缺席时给 10 秒宽限并提示「暂时没有收到房主广播」，核对指纹不会被打断。
- 登录时密码长度、用户代码格式、端口非法都会给出具体原因，不再只是禁用登录按钮。
- Android 上传和下载改为底部浮动进度卡，传输期间可以继续聊天。

## 修复

- 有待批准申请时审批弹窗也能收起（Esc、遮罩、×），申请仍须明确批准。
- 服务端已接受连接后，本地保存连接地址失败不再中止会话，改为提示「已连接 · 地址未保存」。
