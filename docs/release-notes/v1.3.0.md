## LAN Chat 1.3.0 · Aurora

### 新功能
- **三栏布局**：会话列表可拖动调整宽度，会话信息面板按需展开，窄窗口切换为单栏。
- **外观设置**：设置 › 外观 中可选择主题、强调色、消息字号和气泡圆角。
- **快捷键**：Ctrl+K 搜索会话，Ctrl+F 搜索消息，Ctrl+↑/↓ 切换会话，Esc 关闭面板。
- **版本更新提示**：每个版本首次启动时自动提示一次，可在 设置 › 关于 › 版本说明 中手动查看完整更新内容。

### 改进
- 重新设计的启动页：创建与加入聊天室成为主入口；附近聊天室标注 首次确认 / 已信任。
- 聊天区：连续消息自动分组，引用可跳转原消息，支持悬停与右键操作。
- 输入框：每个会话单独保存草稿，支持中文输入法回车、表情面板和回复预览。
- 矢量图标替换字符图标，在不同字体环境下显示一致。

### 修复
- 更新提示的已读状态在退出重启后保留。
- 调整次要文字、消息时间和投递状态的对比度。

### 下载
- `LANChat-Setup-x64.exe`：安装版
- `LANChat-Windows-x64.zip`：免安装版，完整解压后运行 `LANChat.exe`

首次加入请通过可信渠道核对房主证书指纹；跨机器与大文件传输请按[验收清单](https://github.com/DUSK1NG/cross-language-lan-chatroom/blob/master/docs/release-acceptance.md)实测。

安装包未签名，请核对 SHA256。
