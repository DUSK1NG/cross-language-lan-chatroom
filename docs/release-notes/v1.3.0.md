## LAN Chat 1.3.0 · Aurora

### 新功能
- **深色模式**：设置 › 界面 中选择 跟随系统 / 浅色 / 深色，切换时颜色平滑过渡。
- **动画体验**：页面切换、消息入场（自己的从右、他人的从左）、频道列表、群/私滑动指示、未读徽标、成员抽屉与弹窗均加入轻量动画；遵循系统“减少动画”与程序性能档位。
- **版本更新卡片**：每个新版本首次启动时展示一次更新内容，可在 设置 › 关于 › 版本说明 中重新查看。

### 改进
- 重新设计的启动页：创建与加入聊天室成为主入口；附近聊天室标注 首次确认 / 已信任。
- 聊天区：按用户区分的头像颜色、实心的自己消息气泡、悬浮的消息操作条、带聚焦描边的输入框。
- 矢量图标替换字符图标，在不同字体环境下显示一致。

### 修复
- 身份卡不再遮挡频道列表，固定停靠在侧栏底部。

### 下载
- `LANChat-Setup-x64.exe`：安装版
- `LANChat-Windows-x64.zip`：免安装版，完整解压后运行 `LANChat.exe`

首次加入请通过可信渠道核对房主证书指纹；跨机器与大文件传输请按[验收清单](https://github.com/DUSK1NG/cross-language-lan-chatroom/blob/master/docs/release-acceptance.md)实测。
