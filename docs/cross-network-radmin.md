# Radmin VPN / 虚拟局域网自动发现

LAN Chat 不内置、不下载、也不配置 Radmin VPN。请由房主和成员分别安装可信的虚拟局域网工具，并加入同一个私有虚拟网络。

## 自动加入流程

1. 房主在 LAN Chat 中选择“创建本地聊天室”，正常启动房间。
2. 成员在 LAN Chat 中选择“加入局域网聊天室”。页面会持续自动扫描物理局域网和虚拟局域网；房主出现在“附近聊天室”后直接选择即可。
3. 首次连接必须经可信渠道核对房主名称和证书指纹。成员确认后仅保存房主的公开证书。
4. 房主必须在连接审批中明确允许该成员，成员才会进入聊天。

房主会每秒在可用 IPv4 网卡的定向广播地址上发送 UDP `38888` 发现公告；Radmin 常见的 `26.x.x.x` 虚拟网段会参与公告。`198.18.0.0/15` 等代理/测试虚拟网段（例如 FlClash）会被排除，避免同一房主被错误地址覆盖。TCP 聊天连接仍使用端口 `8888` 和现有 TLS 证书校验。

## 自动发现失败时

- 确认双方在线且位于同一个虚拟网络。
- 允许 LAN Chat 的 UDP `38888` 和 `chat-server.exe` 的 TCP `8888` 通过 Windows 防火墙的专用网络。
- 某些虚拟局域网或企业网络会阻止 UDP 广播；这时使用“手动连接”，填写房主的虚拟网 IPv4、端口 `8888` 和公开证书 `server-lan.crt`。

`server-lan.key`、`chat.db`、聊天记录以及虚拟网络工具的账号/令牌都不得共享、同步或提交到 GitHub。
