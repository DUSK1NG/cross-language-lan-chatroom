# S4 执行版：在线群管理与群附件

S3 通过后执行。以服务端、桌面 Online、原生 Android 三端完整交付群能力。先核对现有群创建、详情、历史、退群与私信附件实现，以及服务端和客户端的全部消息分派入口。

## 实施要求

1. **角色和旧群。**在线库迁移到 `user_version=3`，群与成员新增群主、角色、公告及加入时间。新群由创建者担任群主。旧群保留已有成员和历史访问，用可核实的记录或用户批准的归属表补群主。无法核实的群保留群聊，依赖群主管理权限的操作提示归属待确认。
2. **邀请与退出。**沿用好友直接加入规则，被加入者可看到群与邀请来源并退出。本版邀请对象限于好友。新成员仅能读取加入后的消息和附件，旧群已有成员保留原历史范围。用服务端消息顺序记录每次入群的可见边界。退出或被移除后，列表、群消息、下载和后台推送都按新成员状态处理。群主退群前须先转让。
3. **权限与协议。**成员可查看群信息、聊天、收发附件和退出。管理员可邀请自己的好友、移除普通成员和编辑公告。群主可任免或移除管理员、转让给其他成员和修改群设置。角色转让在同一事务完成。为 `group_invite`、`group_kick`、`group_role`、`group_transfer`、`group_update`、`group_announce` 定义权限矩阵及错误。新建群与后续邀请最多 20 人，含群主。能力协商保护旧客户端，群事件只发给需要刷新的账户或设备。
4. **文件、图片和历史。**复用 S3 分块存储，消息、上传和下载明确关联群 ID。发送、发布、历史分页和每次下载校验当前成员状态与可见历史范围。群消息支持文件卡片和图片预览，沿用 S3 的限额和进度反馈。私信和现有群文本历史继续可用。
5. **客户端。**桌面 Online 补齐群会话的基本收发、历史、群详情和管理入口。Android 复用现有群会话，补齐同等群管理与原生附件入口、历史和预览。群设置保留群名和公告，头像及独立群文件列表可随范围冻结延期，聊天内文件仍可查看。成功操作即时刷新，离线回连同步成员状态。推送和未读按群会话归属，点击进入正确群。
6. **兼容性。**旧客户端保留原群文本和退群能力，群主角色的新限制给出可读的服务端错误。未协商群附件能力的客户端把含附件的消息显示为可识别文本，历史页仍可读取。新客户端连旧服务端只显示服务器支持的操作。文档更新协议字段与权限矩阵。

## 验收

```powershell
cargo test --locked -p lan-chat-server -p lan-chat-client-core -p lan-chat-protocol
pnpm --dir frontend run lint
pnpm --dir frontend exec vitest run
pnpm --dir frontend run build
gradle -p android :app:assembleDebug
```

用桌面与 Android 真机验证互相发群消息、图和文件、分页、邀请、退群、管理员任免、转让及通知点击。用旧群数据与至少一个旧客户端复核兼容性，重点覆盖被移除时正在下载、群主退群、通知到达后已退群及旧版陌生能力。记录三端完成情况、兼容边界和延期条目。
