# Flutter 局域网发现人工验收

1. 启动 Flutter Windows Debug 程序，保持在未连接的连接页。
2. 填写用户名和用户代码，点击“搜索局域网主机”。
3. 确认扫描状态出现，并且发现条目只显示主机名称、地址端口和已知/新发现状态。
4. 在 Flutter widget 测试的假核心中，选择“使用此主机连接”，确认命令仅含 `hostId`、填写的用户名和用户代码。
5. 验证手动连接仍保留“公共 CA 文件路径”字段，但不填写或查看任何证书资料。

发现主机的公开 CA 由 C++ 核心自动管理。验收期间不得查看、复制或输入任何证书内容、证书路径或私钥；不得连接真实服务端。
