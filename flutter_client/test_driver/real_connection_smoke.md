# Flutter 双客户端人工验收

本清单只供操作员在受控环境中手工执行；自动化验证不连接任何服务端。

1. 由操作员通过可信渠道向两名测试者提供服务器地址、端口和公共 CA 文件路径。不要向应用或验收记录提供私钥、证书内容、数据库、聊天内容或日志。
2. 在两台 Flutter Windows 客户端分别选择“远程服务器”，输入各自的用户名与用户代码，以及操作员提供的地址、端口和公共 CA 路径。
3. 两端连接后，分别使用“刷新成员目录”和“刷新频道目录”，确认 UI 能显示最新状态。
4. 用管理员身份打开“成员管理”，确认普通身份没有该入口；仅执行获授权的成员操作。
5. 在“设置”中切换性能等级和连接日志开关，确认状态更新。连接日志验收只确认开关状态，不查看或复制日志。
6. 由操作员在两端完成基本互操作验证并记录结果；验收记录只能包含通过/失败和非敏感错误摘要。

验收结束后由操作员断开两端连接。此清单不要求、也不允许读取、输出、复制或保存私钥、证书内容、数据库、聊天或日志。
